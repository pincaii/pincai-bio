# 品才的个人主页

这是我的个人主页静态页面：点击进入遮罩、横幅、圆形头像、彩色社交图标、自定义链接、Discord 实时状态卡片、音乐播放器（进入页面后自动播放）

纯 HTML/CSS/JS

## 文件结构

```
pincai-bio/
├── index.html   # 页面结构和文字（名字、简介、社交、链接）
├── styles.css   # 样式（配色、布局、动效）
├── script.js    # 配置与交互（遮罩文字、Discord 状态、歌曲、自动播放）
└── README.md
```

## 图片素材

- `background.jpg` — 整页背景图（不用模糊）
- `banner.png` — 顶部横幅图
- `avatar.png` — 圆形头像

## Discord 实时状态（重要）

页面的 Discord 状态通过 **Lanyard** 服务读取（`api.lanyard.rest`），它是 Discord 官方允许的第三方公开接口，无需机器人 Token，但有一个前提：

1. 用你的 Discord 账号加入 Lanyard 的服务器，请自行搜索名字加入
2. 加入后 Lanyard 大约每 40 秒同步一次你的公开状态，页面每 30 秒自动刷新，即可显示在线/离开/勿扰/离线、当前在玩的游戏、自定义状态和活动时长。
3. 不加入的话，API 会返回 404，卡片显示"未连接 Lanyard"

页面部署后需要能访问外网（`api.lanyard.rest` 和 `cdn.discordapp.com`），本地双击打开也能直接生效

## 访问计数

横幅左侧的 `👁 数字` 是独立访客数（同一人只计一次，刷新不重复累加），通过免费的服务统计（`busuanzi.ibruce.info`），按部署域名累计，所有访客共享同一个数字，本地直接双击打开时显示 0，**部署上线后自动开始计数**

## 音乐播放器

- 支持上一首 / 下一首 / 播放暂停 / 静音，音量默认 15%，可通过进度条下方的彩虹色音量滑条调节
- 歌曲列表在 `script.js` 的 `CONFIG.songs` 里配置（文件名含空格也能正常引用，建议用 `./文件名.mp3` 形式）

## 注意：编码

本页面文件是 UTF-8 编码（带 BOM）。请用支持 UTF-8 的编辑器（如 VS Code、现代版记事本）打开和保存，不要用 GBK/ANSI 编码保存，否则中文会变成乱码、代码也可能报错
